

### Prerequisit.

1. Install the [Azure CLI (v 2.30.0+)](https://docs.microsoft.com/cli/azure/install-azure-cli)
  1. Login to Azure CLI `az login`
  1. Make sure correct sub is set with `az account show`, `az account set`
1. Install [GitHub CLI](https://github.com/cli/cli) or [Direct GitHub CLI install](https://medium.com/@rabeehco/how-to-install-and-setup-github-cli-on-windows-cdf16115dc04)- To create the secrets
